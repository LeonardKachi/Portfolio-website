Project Overview

The AI-Powered Book Recommendation System is a sophisticated web application that helps users discover books tailored to their interests. By combining Google Books API data with intelligent filtering algorithms, the platform delivers personalized book recommendations based on genre, ratings, page count, and popularity.

This project demonstrates advanced frontend development techniques including state management, debounced search, pagination, theme switching, and wishlist functionality. The application features a clean, modern UI with both light and dark themes, responsive design, and comprehensive accessibility features.

Key Challenges Solved:

  • Efficient API integration with real-time search capabilities
  • State management for complex filtering and pagination
  • Performance optimization with debouncing and lazy loading
  • Accessible UI with keyboard navigation and screen reader support
  • Cross-browser compatibility and responsive design

API Integration

The application integrates with AWS API Gateway to fetch book data from Google Books API:

JavaScript 
async function loadBooks() {
    if (state.isLoading) return;
    
    state.isLoading = true;
    showLoadingState();
    
    try {
        // Construct API query parameters
        const params = new URLSearchParams();
        if (state.searchQuery) params.append('query', state.searchQuery);
        if (state.currentGenre !== 'all') {
            params.append('genre', state.currentGenre);
        }
        params.append('page', state.currentPage - 1);
        params.append('perPage', config.booksPerPage);
        
        // Call API Gateway endpoint
        const response = await fetch(
            `${config.apiEndpoint}?${params.toString()}`,
            {
                headers: {
                    'Content-Type': 'application/json'
                }
            }
        );
        
        if (!response.ok) {
            throw new Error(
                `Failed to fetch books: ${response.status}`
            );
        }
        
        const data = await response.json();
        
        // Process and display books
        state.allBooks = processBooks(data.books);
        state.totalBooks = data.totalItems || data.books.length;
        state.totalPages = Math.ceil(
            state.totalBooks / config.booksPerPage
        );
        
        applyFilters();
        updatePagination();
        showToast(`Found ${state.totalBooks} books`, 'success');
        
    } catch (error) {
        console.error('Error loading books:', error);
        showErrorState('Failed to load books. Please try again.');
    } finally {
        state.isLoading = false;
    }
}

Debounced Search Implementation

Efficient search with debouncing to prevent excessive API calls:

JavaScript 
function debounceSearch() {
    // Clear existing timeout
    clearTimeout(state.searchTimeout);
    
    // Set new timeout
    state.searchTimeout = setTimeout(
        executeSearch,
        config.debounceDelay
    );
}

function executeSearch() {
    // Get search query from input
    state.searchQuery = elements.searchInput
        ? elements.searchInput.value.trim()
        : '';
    
    // Reset to first page
    state.currentPage = 1;
    
    // Load books with new query
    loadBooks();
}
